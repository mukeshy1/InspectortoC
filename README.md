# InspectortoC

Private local project for the C: drive inspection report.

## Overview
This repository contains a GUI-style inspection report showing a summary of the main C: drive sections, including:

- root system folders
- user profiles
- installed program paths
- Windows system area
- clickable folder summaries

## Files
- `index.html` — browser-based GUI report
- `launcher.py` — simple launcher that opens the report in the default browser
- `dist/InspectortoC.exe` — packaged Windows executable version

## Run locally
Open the HTML report in a browser, or run the executable:

- `dist/InspectortoC.exe`

## Notes
This repository is intended for private use and can be kept private on GitHub.
